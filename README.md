# IT Support Home Lab

A collection of hands-on labs I built to practice the daily work of an IT support technician. Everything runs in virtual machines on a laptop with 8 GB of RAM. All accounts and passwords are lab-only test data.

## Labs

| # | Lab | Topics |
|---|---|---|
| 01 | [Active Directory Lab](01-active-directory-lab/) | Windows Server 2022, AD DS, DNS, OUs, groups, password reset, account lockout, Group Policy |

## Skills demonstrated

- Windows Server 2022 installation and configuration
- Active Directory Domain Services and DNS
- User, group and OU management
- Group Policy and account lockout policy
- Basic network troubleshooting (`ping`, `nslookup`, `ipconfig`)
- Virtualization with VirtualBox on limited hardware

## About

I am a computer science graduate building practical IT support skills. Each lab folder has its own README with steps, screenshots and troubleshooting notes.
